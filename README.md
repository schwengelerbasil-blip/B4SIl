# B4SIL – Mix & Mastering

    npm run dev      # http://localhost:5173
    npm run build    # static copy in dist/ (for hosting)

- Audio: put the two files into `site/audio/` – the name must contain `before` / `after`.
- Contact: opens the visitor's mail app addressed to b4ilmixmastering@gmail.com (set in `site/js/main.js` and `site/index.html`).
- No dependencies. The 3D vinyl and the B4SIL lettering run in one WebGL2 scene (`site/js/vinyl.js`).
